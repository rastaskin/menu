Ограничения проекта остаются: без CDN и аналитики, CSP не расширять (шрифт — `'self'`), при изменении `web/` поднимать `VERSION` в `web/sw.js`, селекторы e2e-тестов не ломать или обновить тесты.

## План
1. Прочитать `SKILL.md` Hallmark и правила redesign; тема `references/themes/hum.md`.
2. Nunito 500/600/700 (woff2, кириллица) в `web/fonts/`, `@font-face`.
3. Токены Hum в `web/style.css` (светлая), тёмная версия «тёмный картон», переключатель темы (`data-theme` на `<html>`, в localStorage).
4. Вкладка «Сегодня» (первая), боковая панель на ПК.
5. Остальные экраны: Меню (неделя), Покупки, Дома, Рецепты, Ещё — в стиле Hum.
6. `sloplint`, `npm test`, `npm run test:e2e`, скриншоты (телефон, ПК, тёмная).
7. Показать пользователю, после «да» — коммит, деплой Pages, тег `v0.1.2` для ПК.
