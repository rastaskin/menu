# Формат таблицы «Меню» (для Claude и ручных правок)

Первая строка каждого листа — заголовки. Порядок строк не важен. Недостающие листы приложение создаёт само.

| Лист | Коллекция | Столбцы |
|---|---|---|
| Меню | meals | id (`2026-10-27/ужин`), дата, приём (`завтрак`/`обед`/`перекус`/`ужин`/`с собой`), блюдо, съели, _u |
| Дни | days | id (`d2026-10-27`), дата, день, события, готовка, _u |
| Покупки | shop | id, неделя, раздел, продукт, количество, цена, куплено, есть дома, перенесено домой, ключ, _u |
| Дома | pantry | id, продукт, количество, где (`fridge`/`freezer`/`shelf`), годен до, заметка, _u |
| Рецепты | recipes | id, название, как готовить, _u |
| Правила | rules | id, правило, текст, _u |
| Настройки | meta | ключ, значение, _u. Строка `_rev` — служебная, не трогать |
| Удалено | tomb | запись (`<коллекция>:<id>`), _u |
| Семья | family | id, имя, цвет (`pear`/`blue`/`coral`/`mint`/`kraft`/`sugar`), данные (зашифровано), _u |

## Правила правки
1. **Изменить ячейку** → в той же строке очистить `_u`. Приложение поставит время синхронизации, и правка победит копии на устройствах.
2. **Добавить строку** → уникальный `id`, `_u` пусто.
3. **Удалить** → строку не удалять; добавить на лист «Удалено» `<коллекция>:<id>` с пустым `_u`.
4. Даты — `ГГГГ-ММ-ДД` (принимается и `ДД.ММ.ГГГГ`). Флаги — `TRUE` или пусто. Цена — число.
5. События дня: через `;`, префиксы `a:` и `g:` — занятость членов семьи (синяя и коралловая метки, например `a:Учёба 9:00–15:30`), `z:` ужин из заготовки, `h:` праздник, `o:` прочее.
6. Новый период меню: добавить строки в «Дни» и «Меню» с новыми датами, покупки — с новым номером недели (3, 4…). Приложение само сгруппирует дни по 7.
7. Листы и заголовки не переименовывать, столбцы не добавлять.
8. «данные (зашифровано)» на листе «Семья» — шифр аллергий, веса и заметки; руками не править. Соль и проверочная строка семейного пароля — строки `fam_salt` и `fam_check` на листе «Настройки», их тоже не трогать.
