# Меню — руководство для Claude Code

Семейный планировщик питания: меню на неделю, покупки, продукты дома, рецепты, карточки членов семьи. Без фреймворков. Local-first: данные на устройствах, обмен — через свой релей со сквозным шифрованием (`docs/LOCAL-FIRST.md`); Google Таблица — по желанию, разовый обмен по кнопке (её можно править руками и через Claude). Личные настройки владельца копии, если есть, — в `CLAUDE.local.md` (не в git).

Общайся по-русски, коротко, таблицами и списками.

## Устройство

| Часть | Где |
|---|---|
| Модель и слияние | `web/model.js`: записи с `_u`, надгробия `tomb`, при равном `_u` побеждает таблица; служебные id (`__proto__` и т. п.) отбрасываются |
| Синхронизация | `web/relay.js` + `web/family.js`: ключ семьи (16 байт) → HKDF → AES-GCM записей, HMAC имён, адрес и пропуск на релее; приглашение `#join=` и QR (`web/qr.js`), 12 слов BIP39 (`web/bip39-en.js`) |
| Релей | `relay/`: Cloudflare Worker + Durable Object (SQLite), хранит только шифр, пропуск закрепляется первой записью; пределы: 120 запросов в минуту с IP, новых семей 50 всего и 5 в сутки (реестр `Registry`), 50 МБ и 100 000 записей на семью; пометки об удалении старше 180 дней стираются (`M.TOMB_TTL`); `relay/README.md` |
| Ключ в Google | `web/gdrive.js`: «Войти через Google» — код семьи в `menu-family.json` в appDataFolder Google Диска (доступ `drive.appdata`); входят только устройства того же Google-аккаунта; старый вход без Диска → повторный вход с `prompt=consent` |
| Таблица | `web/sheets.js`: обмен по кнопке; лист на коллекцию, ревизия `_rev` на листе «Настройки», до 3 попыток; недостающие листы создаются сами |
| Фото семьи | коллекция `photos` (id = id карточки, JPEG 160 px data URL): через релей в шифре, в таблицу не попадает (её нет в `SHEETS`); показывается только `data:image/jpeg;base64` |
| Шифрование | `web/vault.js`: аллергии, вес и заметка карточки семьи — AES-GCM-256, ключ из семейного пароля (PBKDF2-SHA-256, 600 000 итераций), id карточки — AAD |
| Интерфейс | `web/app.js`: Сегодня / Неделя (доска: колонка — день, карточка — блюдо; перенос мышью и долгим нажатием пальца, занятое место меняется местами; «+ Добавить» — свой приём пищи) / Покупки / Дома / Рецепты / Ещё (семья, оформление, синхронизация, памятка для ИИ-агентов к таблице) |
| Дизайн | Hallmark, тема Hum: `web/tokens.css`, `web/base.css`, `web/style.css` (штамп Hallmark в первых строках), шрифт Nunito в `web/fonts/`; решения — `docs/REDESIGN-HUM.md` |
| Иконки продуктов | `web/foodicons.js` + `web/icons/food.webp` (64 шт.), сборка спрайта — `tools/make_food_sprite.py` |
| Приложение на ПК | `desktop/src-tauri`: окно Tauri 2 (одна копия: повторный запуск показывает открытое окно), вход в Google (code + PKCE через 127.0.0.1), refresh token — в диспетчере учётных данных Windows, окно получает только access token; автообновление из GitHub Releases |
| Телефоны | Сайт-PWA на GitHub Pages (`.github/workflows/pages.yml`) |

## Проверки

```
npm ci
npm test            # модель, кодек, ключи семьи, QR, релей, синхронизация, шифрование, иконки
npm run test:e2e    # Playwright с поддельными релеем и Sheets API: правки, офлайн, второе устройство по ссылке, семья, смена семьи во время синхронизации, доска недели (мышь и касание через CDP), ключ семьи в Google Диске и фото семьи (поддельный Drive), ПК (подмена __TAURI__)
```

Дизайн: `node ~/.claude/skills/hallmark/scripts/sloplint.mjs web --genre playful --scope app --render` (Hallmark; CHROME_PATH — путь к Edge или Chrome).

## Сборка и релиз

- Сайт: пуш в `main` → тесты → деплой `web/`.
- Релей: `cd relay && npx wrangler deploy` (вручную, из аккаунта Cloudflare владельца).
- ПК: тег `v*` → `.github/workflows/desktop.yml` → `Menu_*_x64-setup.exe` + `latest.json`. Секреты репозитория: `GOOGLE_DESKTOP_CLIENT_SECRET`, `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Сторонние actions закреплены по SHA.

## Правила

- Данные о здоровье (аллергии, вес, диагнозы, препараты) — только в шифре `enc` листа «Семья», никогда открытым текстом в таблице, в коде, в тестах и в коммитах.
- В репозитории нет имён, id таблиц и экспортов данных (`menu-*.json`); тестовые данные — обезличенный пример (`tools/seed.json`).
- Всё из таблицы и с релея попадает в HTML только через `esc()`; новые поля — так же.
- Ссылка `#join=` подключает семью только с подтверждения и заменяет данные устройства данными семьи — чужая ссылка не уносит данные. Ключ семьи — только во фрагменте ссылки, в 12 словах и в IndexedDB; в логах, тестах и коммитах его нет.
- Синхронизация, начатая для прежней семьи, свой результат выбрасывает (`FAMILY.gen` в `web/app.js`); с релея принимаются записи только известных разделов (`M.NAMES`).
- Перед присоединением к семье прежние данные устройства сохраняются в IndexedDB `backup` (кнопка в «Ещё»); адрес приглашения — `appUrl` в `web/config.js`.
- Обмен с таблицей — только по кнопке; ссылки `#sheet=` ничего не подключают.
- Без аналитики, CDN, сторонних скриптов и шрифтов из сети; CSP не расширять (исключения по решению владельца — адрес своего релея и `https://www.googleapis.com` для ключа семьи в Google Диске в `connect-src`).
- Версия программы — `version` в `web/config.js`, равна тегу релиза (desktop.yml проверяет); поднимать вместе с тегом.
- Листы и заголовки таблицы не переименовывать — на них завязан кодек (`SHEETS` в `web/sheets.js`); новые столбцы — только вместе с кодеком.
- При изменении файлов `web/` поднимать `VERSION` в `web/sw.js`.
